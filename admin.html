💳 Razorpay Payment Settings

Powers checkout for both one-time orders and Autopay subscriptions.

⚠️ Two things must be set up OUTSIDE this admin panel, for security:

1. In the Apps Script editor (Project Settings → Script Properties), add: RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET, and RAZORPAY_WEBHOOK_SECRET (make up any string for the webhook secret).

2. In your Razorpay Dashboard → Settings → Webhooks, add this exact URL (replace YOUR_WEBHOOK_SECRET with what you set above), and enable events: payment.captured, subscription.activated, subscription.charged, subscription.halted, subscription.cancelled, subscription.completed:

YOUR_SCRIPT_URL?source=razorpay_webhook&wh=YOUR_WEBHOOK_SECRET

3. For each Routine product, create a matching Plan in Razorpay Dashboard → Subscriptions → Plans, then paste its Plan ID into that product below (Store & Inventory tab).
